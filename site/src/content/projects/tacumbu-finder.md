- Web app to search and report scammers, backed by Supabase and the ListaHU API.
- Native version (Expo / React Native) with a mobile-friendly report feed and native sharing.
- Built with React Query for data, Shadcn/UI and Tailwind on web, Tamagui and Zustand on mobile.
