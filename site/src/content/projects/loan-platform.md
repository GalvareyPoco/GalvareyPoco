- Mobile app with role-based request creation and blacklist checks for automatic rejection.
- In-app chat between analysts and request creators, powered by Supabase real-time events.
- Web review queue that serves one request at a time, with a review timer for performance tracking.
- Admin tools for user management and analytics.
